# AWS + Lambda Integration
## Intrucciones del laboratorio:

Deben realizar el código del diagrama que se está adjuntando como archivo mermaid.

La arquitectura debe poder desplegarse en 3 entornos: DEV, QA y PROD. (Con que solo opere DEV es más que suficiente)

Lo que no esté considerado en el diagrama se puede cambiar/modificar.

Deben adjuntar un PDF incluyendo capturas de que se encuentra desplegado en su cuenta de AWS (evidenciar datos de la cuenta) y el URL de su proyecto con instrucciones de README.md.

Deben evidenciar haber destruido los recursos (terraform destroy*)
